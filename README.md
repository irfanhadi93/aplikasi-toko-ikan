# aplikasi-toko-ikan
aplikasi manajemen toko ikan


Aplikasi web sederhana untuk membantu pencatatan dan pengelolaan toko ikan.

Demo

Live Demo:
https://irfanhadi93.github.io/aplikasi-toko-ikan/

Fitur

- Pencatatan harga ikan
- Pencatatan pembelian
- Pencatatan penjualan
- Pengelolaan stok
- Pencatatan pengeluaran
- Perhitungan modal dan potensi laba
- Pencatatan saldo
- Riwayat transaksi
- Penyimpanan data lokal menggunakan LocalStorage
- Sinkronisasi data menggunakan Firebase Firestore

Teknologi

- HTML
- CSS
- JavaScript
- Firebase Firestore
- LocalStorage
- GitHub Pages

Tujuan

Proyek ini dibuat untuk membantu proses pencatatan toko ikan agar data pembelian, penjualan, stok, dan keuangan dapat dikelola dalam satu aplikasi.

Proyek ini juga merupakan bagian dari proses belajar dan pengembangan kemampuan dalam membangun aplikasi web menggunakan JavaScript dan Firebase.
